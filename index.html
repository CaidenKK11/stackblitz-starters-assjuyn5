What's Inside A Personal Computer?

A reference guide based on CompTIA PC hardware principles.

Personal Computers Overview

The front panel provides access to optical drives, power buttons, temperature displays, and front I/O ports[cite: 2]. The rear panel provides access to power connections, rear motherboard ports, expansion card slots, and hot air vents[cite: 3].

Motherboard

The motherboard is the main printed circuit board (PCB) providing data and power bus connectivity between all hardware components[cite: 7].

Electrical Safety & ESD: Always use ESD wrist straps, grounding mats, and anti-static bags to prevent electrostatic discharge damage[cite: 5].

Functions: Provides system clock timing and routes data between the CPU, RAM, cache, and mass storage[cite: 7, 8].

CPU & Memory Connectors: Features the CPU socket, DIMM slots, M.2 connector, and SATA connectors[cite: 9, 10, 11].

PCIe Slots: PCIe slots come in x1, x4, x8, and x16 lane widths for adapter cards[cite: 13, 14].

PCI Slots: Legacy expansion slots that are not compatible with modern PCIe slots[cite: 15].

Installation: Uses standoffs to secure the motherboard inside the chassis after installing the I/O shield[cite: 18].

Headers: Includes front panel pins, 9-pin USB headers, and audio headers[cite: 20, 21].

CPUs (Central Processing Unit)

The primary processor that executes instructions using a Fetch-Decode-Execute-Writeback architecture[cite: 24].

Socket Types: AMD uses Pin Grid Array (PGA) with pins on the chip[cite: 29]. Intel uses Land Grid Array (LGA) with pins on the motherboard socket[cite: 29].

Cables and Connectors

SATA Interface: Standard data and power cables for internal drives[cite: 34, 35]. SATA Rev 3 supports up to 6 Gbps[cite: 34].

Molex Connector: 4-pin connector delivering +5V DC (Red) and +12V DC (Yellow) power[cite: 37].

Legacy Cables

Video Cables: DVI (digital/analog) and VGA (15-pin analog video)[cite: 41, 42, 43].

Serial Cables: RS-232 serial standard using DB-9 connectors[cite: 44].

Storage Devices

Drive Bays: Case contains 5.25-inch bays for optical drives and 3.5-inch bays for hard drives[cite: 48].

SSDs: Non-magnetic storage with no moving parts connecting via SATA or PCIe M.2 (NVMe)[cite: 49, 50].

HDDs: Uses magnetic spinning platters, spindle, actuator, and read/write heads[cite: 51].

RAID: Combines multiple drives for data redundancy and performance[cite: 52].

Removable Storage: External enclosures, USB flash drives, and memory card readers[cite: 53, 54, 55].

System Memory (RAM)

Virtual Memory: Disk storage space used as backup workspace when physical RAM fills up[cite: 60].

Modules: Full-sized DIMMs for desktops and SODIMMs for laptops[cite: 65].

Multi-Channel Memory: Dual-channel setups require placing RAM sticks into matching color slots (Channel A vs Channel B)[cite: 67, 68].

Graphics / Sound / NIC Cards

Video Cards: Dedicated graphics processor (GPU) featuring DisplayPort, HDMI, and DVI ports[cite: 72, 73].

Sound Cards: 3.5mm color-coded audio jacks (Green = Out, Pink = Mic, Blue = In)[cite: 75, 76].

NIC Cards: Network cards with RJ-45 ports for Ethernet connection[cite: 77, 78].

Peripheral Devices

USB Connectors: Type A, Type B, Micro USB, and reversible USB Type-C[cite: 87, 88].

Displays: Comparing LCD (IPS, TN, VA) with high refresh rate OLED monitors[cite: 90].

Thunderbolt: High-speed 40 Gbps data transfer over USB-C connector[cite: 94].

Lightning: Apple proprietary connector being replaced by USB-C[cite: 95].

Power Supplies And Cooling

Power Supply Unit: Converts AC wall power to internal DC voltages[cite: 98].

Main Power: 24-pin (or 20+4 pin) main motherboard connector[cite: 100, 101].

Modular PSU: Detachable cables to reduce cable clutter in the computer case[cite: 102].

Air Cooling: Thermal paste bridges gaps between CPU and heat sink block, cooled by CPU fan[cite: 105].

Liquid Cooling: Uses a pump, water block, tubing, radiator, and fans to cool high-performance components[cite: 107].
